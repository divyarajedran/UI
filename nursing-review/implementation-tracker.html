How live tracking works

For whoever implements a task

  1. Change the task's status on this page (Not started → In progress → Finished) and add a note, such as the PR or commit.
  2. Click Download status file to get the updated tracker-status.json.
  3. Commit it to the same folder as this page (GitHub: nursing-review/).
  4. Every viewer's page picks it up within 60 seconds (auto-refresh).

Rules

  • A task is marked ✅ FINISHED only when its acceptance check passes. Unstarted tasks carry no marker.
  • Your edits are kept in this browser until the status file is committed. "Discard my local edits" returns to the committed status.
  • Feature flags stay off until the phase exit check passes.
  • File paths: DoctorAPI/…, DoctorApplication/… and DBScripts/… are in Healthcare Management System; DoctorApp/… is the Flutter repo. NEW = create, MOD = change, SQL = migration / SP script.
